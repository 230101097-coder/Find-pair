# Find Pair

Игра на поиск двух пар одинаковых эмодзи.

## Запуск
Откройте `index.html` в браузере.

## Правила
- 4 карточки расположены 2×2.
- Игра случайно выбирает 2 эмодзи и создаёт две пары.
- Если две открытые карточки разные, при нажатии третьей первые две закрываются, а третья остаётся открытой.
- Найденные пары остаются открытыми.
- После нахождения всех пар появляется «Победа!».
- «Заново» начинает новую случайную игру.
